# MAINTENANCE AND SUPPORT

This document defines practical support expectations for a small-business ecommerce store. It is a starting point and should be agreed with the client before launch.

## Monthly Maintenance Can Include

- Dependency updates.
- Uptime checks.
- Backup verification.
- Bug fixes.
- Small content changes.
- Product/admin support.
- Security review.
- Database health check.
- Basic review of logs and errors.

## Not Included Unless Paid Separately

- New major features.
- Marketplace/vendor system.
- Payment gateway integration.
- ERP/POS integration.
- Mobile app.
- Full redesign.
- Migration to another hosting provider.
- Bulk product import unless agreed.
- Advanced analytics.
- Automated SMS/WhatsApp/email campaigns.

## Suggested Monthly Support Plans

These are ranges of service scope, not guaranteed fixed promises.

### Basic

- Small bug fixes.
- Uptime check.
- Backup check.
- Short monthly status review.

### Standard

- Basic support plus small improvements.
- Minor UI/content updates.
- Admin support.
- Help with product or homepage questions.

### Premium

- Standard support plus priority handling.
- New small features when agreed.
- Performance monitoring/review.
- More frequent check-ins.

## Emergency Support

Urgent issues should be defined before launch. Common urgent issues include:

- Site down.
- Orders failing.
- Admin cannot log in.
- Checkout broken.
- Database connection failing.
- Product pages not loading.

Response time and availability should be agreed with the client. Do not promise 24/7 support unless it is part of a paid agreement.

## Hosting Responsibility

Hosting bills are separate from maintenance unless bundled in writing.

Possible ownership models:

- Client owns Vercel, Render, Namecheap, database, and image storage accounts.
- Developer manages hosting accounts for the client under a paid support agreement.
- Client owns billing while developer has limited access for maintenance.

Recommended for long-term business control: the client should own the domain and hosting billing accounts.

## Feature-Change Pricing Guidance

Small changes can be quoted individually or included in a support plan.

Examples of separate paid work:

- Online payment integration.
- Coupons/discounts.
- Product variants.
- CSV import/export.
- Order export.
- ImageKit integration.
- Advanced search.
- Analytics dashboard.
- Delivery integration.
- Multi-language support.
