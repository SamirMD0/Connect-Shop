# CLIENT HANDOVER CHECKLIST

Use this checklist before giving the finished store to a real small-business client.

## Before Handover

- [ ] Production domain is connected.
- [ ] HTTPS is working.
- [ ] Admin account is created.
- [ ] Test credentials are removed or changed.
- [ ] Real business name/contact information is added.
- [ ] Business phone number is correct.
- [ ] WhatsApp number is correct.
- [ ] Business email is correct.
- [ ] Business address/service area is correct.
- [ ] Products and categories are imported or created.
- [ ] Product images display correctly.
- [ ] Policy pages are reviewed by the client.
- [ ] Contact and WhatsApp links are verified.
- [ ] Order flow is tested.
- [ ] Cash-on-delivery flow is tested.
- [ ] Admin order management is tested.
- [ ] Image upload/display is tested.
- [ ] Backup plan is explained.
- [ ] Backup frequency and retention are explained.
- [ ] Backup storage ownership/access is explained.
- [ ] Restore responsibility and approval process are explained.

## Credentials

Hand over credentials securely, not inside GitHub, Markdown files, screenshots, or public chat.

Credentials and account access may include:

- Admin email/account.
- Hosting accounts.
- Domain registrar account.
- Database access if applicable.
- Backup storage or Render PostgreSQL backup access if applicable.
- Image storage access if applicable.
- Redis provider access if applicable.

Use a password manager or secure transfer method. Do not include real passwords in this repository.

## Client Training

Train the client on:

- How to add products.
- How to edit product price, stock, images, and description.
- How to manage categories.
- How to view orders.
- How to update order status.
- How to check customer phone/address/order notes.
- How to update homepage content.
- How to handle cash-on-delivery confirmation.
- How to contact support for technical issues.

## Final Acceptance

- [ ] Client approves the design.
- [ ] Client approves homepage content.
- [ ] Client approves contact information.
- [ ] Client approves product data.
- [ ] Client approves delivery wording.
- [ ] Client approves Privacy Policy, Return Policy, and Terms.
- [ ] Client understands hosting costs.
- [ ] Client understands backup responsibility.
- [ ] Client understands who can access and restore backups.
- [ ] Client understands maintenance/support terms.
- [ ] Client understands which future features cost extra.
