# LAUNCH CHECKLIST

Use this checklist before taking the store live for real customers.

## Technical

- [ ] Frontend deployed.
- [ ] Backend deployed.
- [ ] Database deployed.
- [ ] Migrations applied.
- [ ] Environment variables set.
- [ ] HTTPS working.
- [ ] CORS working.
- [ ] Cookies/session working.
- [ ] CSRF working if used.
- [ ] Redis configured if used.
- [ ] Logs accessible.
- [ ] `robots.txt` loads.
- [ ] `sitemap.xml` loads.

## Storefront

- [ ] Homepage checked.
- [ ] Store page checked.
- [ ] Product search checked.
- [ ] Product filters checked.
- [ ] Product sorting checked.
- [ ] Product pagination checked.
- [ ] Product details checked.
- [ ] Product images checked.
- [ ] Cart checked.
- [ ] Checkout checked.
- [ ] Wishlist checked.
- [ ] Contact page checked.
- [ ] About page checked.
- [ ] FAQ page checked.
- [ ] Privacy Policy checked.
- [ ] Return Policy checked.
- [ ] Terms checked.
- [ ] Mobile layout checked.

## Admin

- [ ] Admin login checked.
- [ ] MFA checked if enabled.
- [ ] Product CRUD checked.
- [ ] Category CRUD checked.
- [ ] Order list checked.
- [ ] Order detail checked.
- [ ] Order status update checked.
- [ ] Homepage CMS checked.
- [ ] Image upload checked.
- [ ] Admin permissions checked.
- [ ] Test admin accounts removed or restricted.

## Business

- [ ] Phone number correct.
- [ ] WhatsApp number correct.
- [ ] Email correct.
- [ ] Address/service area correct.
- [ ] Working hours correct.
- [ ] Delivery rules correct.
- [ ] Cash-on-delivery wording correct.
- [ ] Return Policy reviewed.
- [ ] Privacy Policy reviewed.
- [ ] Terms reviewed.
- [ ] Product prices checked.
- [ ] Stock values checked.

## Final

- [ ] Test order placed.
- [ ] Test order appears in admin.
- [ ] Test order status updated in admin.
- [ ] Test order/customer contact details verified.
- [ ] Test data removed.
- [ ] Real products added.
- [ ] Backup created before launch.
- [ ] Client trained.
- [ ] Support plan agreed.
- [ ] Hosting responsibility agreed.
- [ ] Domain ownership confirmed.
